# Contributing

This is an experimental open-source simulator. Small, inspectable contributions are preferred.

1. Read [AGENTS.md](AGENTS.md) and [SPEC](docs/SPEC.md).
2. Install with `python -m pip install -e ".[dev]"`; run `python -m pytest`.
3. For legal behavior, cite official primary materials, effective date and exact section; mark uncertain interpretations. Do not paste invented judgments or conflate legal systems.
4. Include tests for happy path, denied security actions, strict/realistic differences and actor perspective isolation.
5. Keep synthetic scenarios free of personal data. Do not put API keys, real legal records or unlicensed case-law corpora into pull requests.
6. Explain limitations and do not imply legal validation from passing software tests.
